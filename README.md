# Star Drifter

Un piccolo gioco di esplorazione spaziale — vola tra i pianeti, atterra, esplora, combatti i
predoni, segui la storia del Relitto della Vega. Prototipo giocabile, pensato come pezzo di
portfolio.

## Come si gioca

Apri `index.html` in un browser (doppio click, funziona anche da file locale). Nessuna
installazione, nessun server, nessuna build.

## Comandi

- **Frecce direzionali** o **WASD** — movimento (in volo e a terra)
- **SPAZIO** (o **A**) — spara
- **E** (o **B**) — atterra / decolla

## Tecnologia

Vanilla JavaScript + HTML5 Canvas, zero dipendenze a runtime, zero build step. L'intero motore
(gioco + arte incorporata come immagini base64 nei file `.js`) sta in **~950 KB**, 20 file in
tutto.
